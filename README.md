# Módulo A · JavaScript asíncrono y consumo de APIs

Material educativo del SENA (ADSO), preparado para Node.js 20+ y despliegue posterior en Vercel. Instructor: **Julian Salazar Pineda**.

## Ejecutar
`npm start` y abre `http://localhost:5500`. También puedes usar `php -S localhost:5500` con PHP 8+. No uses `file://`.

El frontend es estático y puede publicarse en Vercel. Para conservar la ruta de prueba al desplegar, debe añadirse una función serverless equivalente a `POST /test.php`.
